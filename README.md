## О проекте

ЖК «Ленская» — премиальный жилой комплекс бизнес-класса на правом берегу Камы в Перми. 5 корпусов, 709 квартир от 25 до 120 м² с потолками 3,1 м. Современная архитектура, панорамное остекление, благоустроенная территория 2,5 га. Рядом набережная, парки, школы и ТЦ.

## Возможности

- **Адаптивный дизайн** — корректное отображение на всех устройствах
- **Интро-заставка** — анимированная загрузка при первом посещении
- **Мобильное меню** — полноценная навигация на смартфонах
- **Модальные формы** — запись на просмотр квартиры
- **Галерея** — фильтрация по категориям, лайтбокс с навигацией
- **Динамическая шапка** — изменение фона при прокрутке
- **Избранное** — сохранение в localStorage
